# The Don Street Restaurant · website

Static site for The Don Street Restaurant, Curaçao.

- `index.html`: landing page
- `order.html`: online ordering. Orders are sent to The Don's WhatsApp (+599 9 565 2810) with the full order, total and customer details.

Menu and prices live in the `MENU` array at the top of the script in `order.html` (prices in XCG).
